## Social-preview placeholder

[social-preview-placeholder.svg](assets/social-preview-placeholder.svg) is an
editable 1280 × 640 layout placeholder, not an installed GitHub social preview.
It is deliberately labeled as a placeholder and is not displayed as the README's
result figure.

Before using a final preview:

1. Finalize the title and factual result line; remove the placeholder label.
2. Export to PNG, JPG, or GIF under 1 MB. GitHub recommends 1280 × 640 pixels.
3. Upload the final image under repository **Settings → Social preview → Edit**.

Committing an image does not configure GitHub's social-preview setting. The
placeholder has not been uploaded to that setting.

See [GitHub's social-preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
